# Tabmark

一个**本地优先**的书签启动器，替换 Firefox 新标签页。界面参考 Chrome 书签扩展 Markoob 0.5.0 的公开设计，代码为独立实现（未复制上游源码、字体或图片），不加载任何远程资源。

> 打开新标签页，搜索框已在等你；左边是文件夹树，右边是置顶、最近浏览与所有文件夹。

**环境要求**：Firefox 140 及以上（Manifest V3 + `data_collection_permissions` 声明基线；Firefox for Android 未适配）。

**v2.0 重构**：推翻 v1 的"多分区平铺"主区与过度配置，改为单一导航面 + 一页式设置。移除了首次引导、行/列布局、卡片/紧凑样式、字号与书签宽度调节、隐藏书签等功能——保留的都是日常真正会用的。

**v2.1**：补上四件更常用的事——文件夹聚合视图（点一个文件夹，里面所有层级的书签一次铺开）、可拖拽且可收起的侧栏、全局键入的搜索下拉（含搜索引擎切换）、右上角「整理」（备份 / 去重 / 补图标 / 清理），以及可选背景墙纸。

**v2.3.2**：移动端搜索修复——demo 预览下网络搜索真正打开页面（同步 window.open，绕过弹窗拦截的异步手势丢失）；搜索框改为表单提交 + `enterkeyhint="search"`（键盘回车显示搜索键，绕开输入法吞 Enter 的问题）。列布局对齐 markoob 语义：卡片风格固定行布局，紧凑风格才可切换行 / 列；列布局 = 每个分组一列、组内书签纵向堆叠，各列并排铺满自适应换行。

**v2.2.1**：书签行距放宽（紧凑行 34→40px、网格间距 8→10px）；字体大小 / 书签宽度改为 markoob 式「调整」滑杆——点「调整」弹出底部调整条，拖动实时预览（字体 0.8–1.3，宽度 0.5–1.5），点 ✓ 保存；新增 Firefox Android 自适应布局（≤860px 抽屉式侧栏 + 汉堡菜单 + 单列卡片），已在真机 Firefox 验证。

**v2.2**：视觉全面对齐 markoob——冷灰墨色 + 紫罗兰主色 + 发丝线边框；背景墙纸铺满整个页面（侧栏变为玻璃层融入其中）；书签区取消居中限制、保持全宽；外观新增「书签风格」（卡片 / 紧凑）、「布局」（行 / 列）、字体大小、书签宽度与禁用动画开关，均带预览缩略图。

## 功能

- **新标签页书签台**：左侧文件夹树（全部书签 / 置顶 / 最近浏览 / 各文件夹），内容区一次只呈现一个视图，不再重复平铺。
- **全部视图分节**：置顶（最多 6 张 + 查看全部）→ 最近浏览（来自历史、自动排除已收藏，可关）→ 所有顶层文件夹。
- **文件夹聚合视图**：点侧栏任一文件夹，右侧按子文件夹分节、从上到下依次铺开每节的书签（含嵌套子文件夹，如「开发 › 前端」）；单层文件夹直接以紧凑行呈现，一屏扫完。
- **全局键入搜索**：不点搜索框也能直接打字，结果以**下拉浮层**展开（不再整页切换）；`↑ ↓` 选中、`Enter` 打开、`Esc` 关闭，底部永远保留「用 XX 搜索」一行。
- **搜索引擎切换**：点搜索框左侧字母徽标弹出引擎列表（Google / Bing / DuckDuckGo / 百度 / 夸克 / Yandex / 知乎 / 小红书 / bilibili），默认 Google；可添加自定义（`%s` 占位）、隐藏、删除、拖拽排序、恢复默认。
- **可调侧栏**：拖右侧边缘调宽（168–340px，双击复位），一键收起为图标栏（首字图标，重名自动取末字区分）。
- **整理面板**：导出全部书签为 JSON 备份、扫描并删除重复书签（同一网址，未备份先拦）、从已打开标签页补全站点图标、清理空文件夹与无标题书签。
- **背景墙纸**：6 套内置渐变或本机图片（压缩后存本地），带遮罩浓度调节；开启后侧栏、顶栏与卡片转为半透明玻璃质感。
- **完整管理**：右键打开 / 新窗口 / 隐私窗口 / 置顶 / 编辑 / 复制链接 / 二维码 / 删除；文件夹支持全部打开、重命名、递归删除。
- **删除可撤销**：删除后进 toast 确认，一键撤销，置顶位置也会一并恢复。
- **拖拽整理**：书签拖进文件夹即移动（带防自吞校验）；置顶区可拖拽重排。
- **二维码**：本地生成，支持下载 PNG / 复制链接，方便发到手机。
- **排序**：默认 / 名称 / 最近添加 / 使用频率，主区顶栏一键切换。
- **一页式设置**：外观（主题、语言、墙纸）、书签（打开方式、最近浏览、侧栏宽度）、搜索（引擎、历史参与搜索）、数据（整理、清除使用记录）、关于与快捷键表。
- **工具栏弹窗**：收藏当前页（可选文件夹）、编辑标题与链接、改用页面标题、二维码、复制链接、删除（可撤销）。
- **默认零网络请求**：字体、图标、二维码全部本地；不加载 CDN、不调用 favicon 云服务、无遥测。（「向站点请求图标」是设置里的显式开关，默认关闭。）

## 安装

### 临时载入（开发 / 自用，最快）

1. 打开 `about:debugging#/runtime/this-firefox`
2. 点「临时载入附加组件…」
3. 选择本目录下的 `manifest.json`
4. 打开一个新标签页

> 重启 Firefox 后临时附加组件会被移除，需要重新载入。适合先试用。

### 永久安装（需要签名）

Firefox Release 版只允许安装已签名的扩展。两条路：

1. **提交 AMO 自发行**：把 `tabmark-firefox.zip` 上传到 [addons.mozilla.org](https://addons.mozilla.org/developers/) 走签名（可选「仅自发行」，不必公开上架），下载签名后的 `.xpi` 安装。
2. **开发版浏览器**：Firefox Developer Edition / Nightly 中把 `xpinstall.signatures.required` 设为 `false`，再通过 `about:addons` 的「从文件安装附加组件」载入 zip。

### 打包

```bash
cd tabmark-firefox
zip -r ../tabmark-firefox.zip . -x "*.DS_Store"
```

zip 根目录必须直接包含 `manifest.json`。

## 权限说明

| 权限 | 用途 |
|---|---|
| `bookmarks` | 读取、创建、编辑、移动、删除书签与文件夹 |
| `history` | 生成「最近浏览」、搜索历史（均可在设置中关闭） |
| `storage` | 保存设置、置顶、使用频率、favicon 缓存 |
| `tabs` | 弹窗读取当前标签页标题与 URL；后台缓存已打开站点的图标 |
| `contextMenus` | 页面右键「收藏到 Tabmark」 |
| `search` | 搜索无结果时调用 Firefox 默认搜索引擎 |

**没有申请任何 host 权限**，扩展不读取网页内容，也不发起网络请求。

## 隐私

- 书签、历史、使用频率、设置全部存放在 `storage.local`。
- 「最近浏览」与搜索的历史匹配都在本地运行，不上传任何数据；设置里可一键清除使用记录。
- favicon 不使用 Google / DuckDuckGo 等第三方服务：优先用后台缓存的本地 `data:` 图标，没有则显示字母色块。只有用户在整理面板里显式打开「向站点请求图标」，才会直接向该站点请求 `/favicon.ico`（不经过任何第三方）。
- 背景墙纸图片在本机压缩后存进 `storage.local`，不上传。
- 搜索引擎只是 URL 模板（`%s` 占位），切换引擎不涉及任何内置搜索 API。
- 二维码在本地用 canvas 生成。
- 界面使用系统字体栈（不打包字体文件，也不请求网络字体）。

## 与 Chrome 版的差异

| Chrome 版 | Firefox 版 |
|---|---|
| 「在新标签组打开」 | Firefox 无标签组 API，改为「在新窗口打开」 |
| 隐私窗口直接可用 | 需用户在 `about:addons` → 扩展详情中允许「在隐私窗口中运行」，否则给出提示 |
| `file://` 书签可直接打开 | Firefox 扩展不能打开本地文件，改为复制链接并提示 |
| `_favicon/` 读取站点图标 | Firefox 无此 API；用字母色块 + `tabs.onUpdated` 的本地图标缓存 |
| 9 种语言 | 中文 / English（跟随浏览器或手动选择） |
| 布局 / 密度 / 字号 / 宽度等外观配置 | v2 移除，只保留主题与语言，外观由设计令牌统一驱动 |
| 反馈表单、更新日志、捐赠 | 不包含，保持本地与克制 |

## 快捷键

| 按键 | 行为 |
|---|---|
| 任意字符 | 直接开始搜索（全局键入，不聚焦输入框也会进入搜索框） |
| `Ctrl/Cmd + K`、`/` | 聚焦搜索 |
| `Ctrl/Cmd + N` | 新建书签 |
| `Ctrl/Cmd + ,` | 打开设置 |
| `↑ ↓` | 搜索结果中上下选中条目（`Enter` 打开；无选中则走网络搜索） |
| `← →` | 在书签网格 / 菜单中移动焦点 |
| `Enter` | 打开当前书签 / 确认对话框 |
| `Esc` | 分层关闭：引擎菜单 → 搜索浮层 → 对话框 → 清空搜索 |
| `Shift + F10`、菜单键 | 打开当前项的右键菜单 |
| `Tab` / `Shift + Tab` | 常规焦点移动 |

## 已知限制

- 首次打开极大数据量（数千条）时，网格使用 `content-visibility` 渐进渲染；搜索仍在内存中完成。
- 不支持云同步；换设备请用 Firefox 自带的书签同步。
- 隐私窗口内使用需用户显式授权（Firefox 的安全模型）。
- 未适配 Firefox for Android。
