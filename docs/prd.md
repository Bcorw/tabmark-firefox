## 2. 目标用户与场景

Firefox 桌面用户，书签数量 50–2000 条，常用站点 10–30 个。打开新标签页的动机是「去某个地方」，不是「看仪表盘」。
因此首屏必须：**搜索框立即聚焦可用 → 一眼看到常用 → 一次点击到达**。任何装饰都不能拖慢这条路径。

## 3. 功能范围（P0 必须）

### 3.1 新标签页
1. **覆盖新标签页**（`chrome_url_overrides.newtab`），无外部网络请求、无 CDN、无遥测。
2. **文件夹侧栏**：读取 Firefox 书签树（工具栏/书签菜单/未分类/移动端），可展开折叠；显示子项数量；空文件夹可隐藏；侧栏可折叠、可拖拽调宽（宽度持久化）。
3. **书签主区**：
   - 视图布局：`row`（等高网格）/ `column`（瀑布多列）；
   - 卡片样式：`card`（图标 + 标题 + 域名）/ `compact`（单行）；
   - 排序：默认（书签原始顺序）/ 使用频率 / 字母 / 添加时间，升降序；
   - 置顶区：书签与文件夹都可置顶，置顶顺序可拖拽调整并持久化；
   - 推荐区：「为你推荐」最多 6 条，来自使用频率 + 浏览历史（可关闭）；「来自历史记录」补充未收藏的高频页面。
4. **搜索**：即时过滤书签（标题/URL/域名）与文件夹；可选包含历史记录；无结果时提供「在网页中搜索」入口（Firefox `browser.search.search`）。`⌘K / Ctrl+K` 聚焦，`Esc` 清空，`↑↓←→` 移动，`Enter` 打开。
5. **右键菜单**（自绘，非浏览器原生）：
   - 书签：新标签页打开 / 新窗口打开 / 隐私窗口打开 / 二维码 / 置顶或取消 / 隐藏 / 编辑 / 复制链接 / 删除；
   - 文件夹：全部在新标签页打开 / 全部在新窗口打开 / 添加子文件夹 / 重命名 / 置顶 / 隐藏 / 删除；
   - 空白处：添加书签 / 添加文件夹 / 切换布局 / 进入设置。
6. **增删改**：添加/编辑书签（标题、URL、所属文件夹）、添加/重命名/删除文件夹（删除需二次确认，提示将连同内容删除）。
7. **拖拽**：书签拖到文件夹 = 移动；书签之间拖拽 = 排序（仅默认排序时可用，其他排序给出提示并可一键切回默认）；置顶区内部可排序。
8. **二维码**：本地生成（无第三方请求），支持下载 PNG、复制链接；用于把桌面书签发送到手机。
9. **设置面板**：主题（跟随系统/浅色/深色）、布局、卡片样式、字号、书签宽度、隐藏空文件夹、自动打开上次文件夹、搜索含历史、书签打开方式（新标签页/当前页）、关闭动画、临时显示隐藏项、语言（自动/中文/English）、关于。
10. **首次使用引导**：4 步（推荐与隐私 / 高效管理 / 外观自定义 / 便捷弹窗），可跳过，完成后写 storage。
11. **Toast 通知**：轻量、可撤销（删除书签/文件夹时提供「撤销」）。

### 3.2 工具栏弹窗（popup）
1. 当前标签页信息（favicon、标题、URL）。
2. 未收藏：一键收藏到指定文件夹；已收藏：显示状态，可编辑标题/文件夹、取消收藏。
3. 「与页面标题同步」按钮（书签标题 ≠ 页面标题时出现）。
4. 二维码查看。
5. 打开新标签页 / 打开设置。
6. 键盘：`Enter` 保存，`Esc` 关闭。

### 3.3 后台
1. 安装时初始化默认设置与右键菜单（页面内自绘菜单为主，`browser.contextMenus` 用于书签栏/页面右键「收藏到 Markoob」可选）。
2. 记录书签打开次数（`storage.local`），供频率排序与推荐；只存 URL 与计数，不上传。
3. 新标签页打开时清理过期使用记录（>180 天）。

### 3.4 Firefox 适配差异（必须按此实现）
- Manifest V3，但后台用 `background.scripts`（Firefox 不支持 `service_worker`）。
- `browser.*` Promise API；保留 `chrome.*` 兜底不重要，但不要用 Chrome-only 权限 `favicon`、`search` 之外的未支持项。
- **无「标签组」**：原版「在新标签组打开」改为「在新窗口打开」。
- **隐私窗口**：`browser.windows.create({ incognito: true })` 可能因用户未授权而失败；失败时 toast 提示「请在扩展详情中允许隐私窗口」。
- **本地文件 URL**：Firefox 扩展不能直接打开 `file://`；检测到 `file://` 时提示复制链接。
- favicon 获取：**Firefox 没有 `_favicon/` 与 `favicon` 权限**（已查证，仅 Chromium 支持）。因此：
  1. 主方案为**字母/首字色块**（由域名哈希取色，保证同一站点稳定）；
  2. 增强方案：后台监听 `tabs.onUpdated`，把 `favIconUrl` 为 `data:` 的图标按 hostname 缓存到 `storage.local`（上限 300 条），新标签页优先用缓存图标，无缓存再用色块；
  3. **禁止**请求站点 `/favicon.ico`，禁止 Google/DuckDuckGo/icon.horse 等外部图标服务（会产生网络请求并泄露浏览行为）。
- 新标签页必须能在**无扩展 API 的静态预览**下以 demo 模式运行（用于设计评审），demo 数据仅本地。

## 4. 非目标
- 不实现云同步、账号、AI 推荐、导入 Chrome 书签（Firefox 自身可导入）。
- 不做移动端适配（仅桌面，最小 900px；窄窗口侧栏自动折叠）。
- 不复制原扩展的付费/反馈表单/更新日志。

## 5. 设计与体验要求
- 视觉方向由 `frontend-design-architect` 产出，必须**避免通用 SaaS 仪表盘感**；要有书签/纸张/索引卡的隐喻但不过度装饰。
- 明暗两套主题同等完成度；正文对比度 ≥ 4.5:1；焦点环可见；`prefers-reduced-motion` 下禁用动效。
- 所有图标为内联 SVG（stroke 1.5），不引入图标库。
- 空状态、加载骨架、错误态（书签 API 不可用）都要设计。
- 中文为第一语言，英文完整可用；文案避免机器翻译腔。

## 6. 交付物
```
markoob-firefox/
  manifest.json
  background.js
  newtab/newtab.html|css|js
  popup/popup.html|css|js
  shared/{tokens.css, i18n.js, api.js, qr.js, icons.js, demo-data.js}
  assets/fonts/lexend-*.woff2, icon-*.png
  docs/{prd.md, feature-inventory.md, design-spec.md, ux-spec.md}
  README.md（安装步骤、权限说明、与 Chrome 版差异）
```
最终打包 `markoob-firefox.zip`（可直接在 `about:debugging` 临时载入；签名后可永久安装）。

## 7. 验收
- `web-ext lint` 无 error（warning 允许，需说明）。
- 静态 demo 可完整浏览：侧栏、搜索、置顶、推荐、右键菜单、设置、二维码、弹窗预览。
- 真机 Firefox 载入后：新标签页替换生效、书签增删改即时同步、拖拽移动生效、弹窗收藏生效。
- 无任何网络请求（DevTools Network 为空，字体本地）。
