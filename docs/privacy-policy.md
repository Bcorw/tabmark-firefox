# Tabmark 隐私政策 · Privacy Policy

最后更新 / Last updated: 2026-11-07

---

## 中文

Tabmark 不收集、不存储、不传输任何个人信息。

- **书签与浏览历史**：扩展通过 Firefox 的书签与历史接口读取这些数据，仅在你的设备上用于显示书签和计算本地推荐，不会离开你的浏览器。
- **本地存储**：设置、置顶项、隐藏项、使用频率与站点图标缓存保存在 Firefox 的本地扩展存储（`storage.local`）中；卸载扩展即随之删除。
- **无网络请求**：扩展不发起任何网络请求，不包含分析、遥测、广告或崩溃上报组件，也不读取你访问的网页内容。
- **无网站访问权限**：扩展未申请任何 host 权限，无法读取或修改网页。
- **搜索跳转**：当你在扩展内触发「网页搜索」时，浏览器会按默认搜索引擎打开结果页。该次跳转由 Firefox 与相应搜索引擎的隐私政策约束，扩展本身不上传任何内容。
- **二维码**：在你的设备上本地生成，不经过任何服务器。

若你通过 Firefox 账户启用书签同步，那是 Firefox 自身提供的功能，与 Tabmark 无关。

## English

Tabmark does not collect, store, or transmit any personal data.

- **Bookmarks and history** are read through Firefox's bookmarks and history APIs and processed entirely on your device to render the page and compute local recommendations. They never leave your browser.
- **Local storage**: settings, pinned items, hidden items, usage counts and site-icon cache live in Firefox's extension-local storage (`storage.local`) and are removed when the add-on is uninstalled.
- **No network requests**: the add-on performs no network requests, contains no analytics, telemetry, advertising or crash-reporting components, and does not read the content of the pages you visit.
- **No host permissions**: the add-on requests no host permissions and therefore cannot read or modify web pages.
- **Search hand-off**: when you trigger a web search from the add-on, Firefox opens the results page using your default search engine. That navigation is governed by Firefox's and the search provider's own privacy policies; the add-on itself uploads nothing.
- **QR codes** are generated locally on your device, with no server involved.

If you enable bookmark sync through a Firefox Account, that is a Firefox feature and is unrelated to Tabmark.
