## 0. 上传与兼容性

上传 `tabmark-firefox.zip`（约 0.24 MB，manifest 在根目录）。

兼容目标**只勾选 Firefox 桌面**：

- ✅ Firefox（桌面，≥140）
- ⬜ Firefox for Android —— **不勾选**（见下方说明）

> **为什么不支持 Android**：本扩展的核心能力依赖 `chrome_url_overrides`（覆盖新标签页）、`bookmarks`、`history`、`contextMenus` 四类 API，而 Firefox for Android 目前均不支持（Mozilla 官方文档明确列出）。manifest 因此未声明 `gecko_android`，AMO 也不会提供 Android 勾选项——这是平台限制，不是遗漏。Android 用户的书签管理方案（root/LSPosed 模块）另行交付。

## 3. 描述（Description，支持 Markdown）

````markdown
Tabmark 把新标签页变成一张书签台：左边文件夹树，右边一屏铺开你的书签；搜索框始终在手边。它不联网、不收集数据，所有计算都在你的设备上完成。

## 功能

- **文件夹聚合视图** — 点任一文件夹，右侧按子路径分节、从上到下铺开每节的书签（含嵌套层级），一屏扫完，不用层层点进去。
- **卡片 / 紧凑风格 + 行 / 列布局** — 卡片风格即行布局；紧凑风格下可切换「列布局」：每个分组一列、组内书签纵向堆叠，各列并排铺满。
- **书签宽度与字体大小** — 设置里拖动滑杆实时预览（0.5–1.5 / 0.8–1.3），行高与间距随之联动；也可禁用书签动画。
- **全局键入搜索** — 不点搜索框直接打字，结果下拉展开，`↑↓` 选中、`Enter` 打开；底部始终保留「用 XX 搜索」。内置 9 个搜索引擎（Google / Bing / DuckDuckGo / 百度 / 夸克 / Yandex / 知乎 / 小红书 / bilibili），可添加、隐藏、排序或恢复默认。
- **最近浏览 = 历史记录工具** — 最近浏览页提供历史搜索、日期范围（今天 / 昨天 / 近 7 天 / 近 30 天 / 全部）与一键清除历史；默认显示今日浏览。
- **背景墙纸** — 内置渐变或本机图片（本机压缩存储），遮罩浓度可调；**文字颜色**可自动适应墙纸深浅，也可手动指定浅色 / 深色。
- **可调侧栏** — 拖动边缘调宽（168–340px），双击复位；一键收起为图标栏，节省横向空间。
- **整理面板** — 导出全部书签为 JSON 备份、扫描并删除重复书签、从已打开标签页补全站点图标（可选向站点请求图标，默认关闭）、清理空文件夹与无标题书签。
- **完整管理** — 右键即可在新标签页 / 新窗口 / 隐私窗口打开，或置顶、编辑、复制链接、生成二维码、删除；删除可撤销。书签可拖进文件夹移动，置顶区可拖拽重排。
- **二维码** — 本地生成，可下载 PNG 或复制链接，方便发到手机。
- **一页式设置** — 外观（主题、语言、墙纸、书签风格/布局、字体与宽度）、书签（打开方式、最近浏览）、搜索（引擎管理、历史参与搜索）、数据（整理、清除使用记录）与快捷键表，收在一个对话框里。
- **工具栏弹窗** — 一键收藏当前页（可选文件夹）、编辑标题、改用页面标题、查看二维码。

## 快捷键

- 任意字符 — 直接开始搜索
- `Ctrl/Cmd + K`、`/` — 聚焦搜索
- `Ctrl/Cmd + N` — 新建书签；`Ctrl/Cmd + ,` — 打开设置
- `↑↓` — 搜索结果选中；`←→` — 卡片间移动焦点
- `Enter` — 打开当前项 / 确认对话框
- `Esc` — 分层关闭：引擎菜单 → 搜索结果 → 对话框
- `Shift + F10`、菜单键 — 当前项右键菜单

## 隐私

扩展默认不发起任何网络请求。站点图标优先使用后台缓存的本地数据，没有则显示字母色块；只有显式打开「向站点请求图标」时才会直接向对应站点索取 `favicon.ico`。二维码本地生成，墙纸图片本机压缩后保存。书签、历史、使用频率与设置只存本机，卸载即清除；无遥测、无分析、无第三方服务。

## 已知限制

- 隐私窗口首次使用需在扩展管理中允许，这是 Firefox 的安全模型。
- 无法直接打开 `file://` 本地文件（Firefox 限制），此时改为复制链接。
- 不含云同步，换设备请用 Firefox 账户自带的书签同步。

## 反馈
````

## 9. 给审核员的备注（Notes to Reviewer）

```
审阅说明 — Tabmark 1.0.0（Firefox 桌面版）

【构建方式】纯静态 WebExtension，没有构建步骤、打包器、压缩或混淆。zip 内容即源码，可逐行审阅；所有 JS 为可读的 ES5/ES2019 语法。

【无动态执行】未使用 eval、new Function、setTimeout("string")、importScripts，无内联事件处理器。

【网络请求】默认不发起任何网络请求：无 fetch / XMLHttpRequest / WebSocket / sendBeacon，HTML/CSS 无远程引用。唯一例外：用户在整理面板显式打开「向站点请求图标」后，卡片以 <img src="https://<站点>/favicon.ico"> 直接向书签所在站点取图标（不经过第三方服务，默认关闭）。代码中的 http(s) 字符串仅三类：注释里的来源说明、演示模式的书签网址（仅渲染卡片）、搜索引擎 URL 模板（仅在用户回车搜索时由浏览器导航）。

【数据使用】data_collection_permissions.required = ["none"]。书签与历史经 browser.bookmarks / browser.history 读取，用于界面展示与搜索；结果缓存在 storage.local，不上传。墙纸图片由用户本机选择，canvas 压缩后存 storage.local。「清除历史」使用 browser.history.deleteAll()，仅在用户于最近浏览页点击清除并确认后调用。

【权限用途】
- bookmarks — 读取、创建、编辑、移动、删除书签与文件夹
- history — 最近浏览页与搜索的历史匹配；历史清除（用户确认后）
- storage — 设置、置顶、使用频率、图标缓存、墙纸图片
- tabs — 弹窗读取当前标签页标题/URL；后台缓存站点图标
- contextMenus — 页面与链接右键菜单「收藏到 Tabmark」
- search — 保留默认搜索引擎能力（引擎切换本身用 URL 模板，不依赖此 API）
未申请任何 host 权限。

【测试步骤】
1. about:debugging#/runtime/this-firefox → 临时载入 → 打开新标签页（chrome_url_overrides.newtab）。
2. 侧栏点任一文件夹 → 聚合视图按子路径分节铺开；拖侧栏右缘调宽（168–340px），双击复位，可收起为图标栏。
3. 直接敲字 → 搜索下拉，↑↓ 选中、Enter 打开；点搜索框左侧徽标 → 引擎切换菜单（含「管理搜索引擎」）。
4. 侧栏「最近浏览」→ 顶栏有历史搜索 / 日期范围（默认今天）/ 清除历史。
5. 右上角「整理」→ 导出备份 / 扫描重复 / 补全图标 / 清理。
6. 设置 → 外观：卡片/紧凑风格、行/列布局（列布局仅紧凑可用）、字体大小与书签宽度滑杆、墙纸与文字颜色（自动/浅色/深色）。
7. 右键卡片可见全部操作；工具栏图标弹出收藏面板（含二维码）。
8. 无浏览器 API 环境直接打开 newtab/newtab.html 即进入演示模式（内置示例数据）。

【设计来源】视觉与信息结构参照一款 Chrome 书签扩展（Markoob 0.5.0）的公开设计，代码为完全独立实现：未复制上游任何源码、字体或图片，图标自制。为避免混淆使用独立名称 Tabmark。
```
